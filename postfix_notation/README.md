## Запуск

```bash
# Передавайте выражение в кавычках:
python3 main.py "2 3 ~"
```

## Запуск через Makefile

```bash
# 1. Установить зависимости (pytest, pytest-cov)
make install

# 2. Запустить программу 
make run 

# 3. Запустить все тесты
make test

# 4. Запустить тесты с отчетом о покрытии
make coverage

# 5. Очистить временные файлы кэша
make clean

# 6. Выполнить всё вместе (установка, тесты, запуск)
make all
```
