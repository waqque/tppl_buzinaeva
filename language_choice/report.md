# Выбор парадигмы и языка программирования

## 1. Обработка изображений в реальном времени

**Парадигма:** императивная (четкая последовательность команд, работа с памятью напрямую)

**Язык:** C++

**Почему:** данных очень много и они идут непрерывно, поэтому нужен быстрый язык без лишних задержек. C++ даёт полный контроль над памятью и скоростью.

---

## 2. ML-сервис прогноза погоды

**Парадигма:** объектно-ориентированная / декларативная (использование готовых библиотеки, описание что сделать, а не как именно)

**Язык:** Python

**Почему:** нужно быстро сделать прототип за 2 недели. В Python много готовых ML-библиотек, и код на нём пишется быстро(а по времени мы ограничены).

---

## 3. UI торгового терминала

**Парадигма:** объектно-ориентированная/реактивная(интерфейс состоит из отдельных "виджетов", которые автоматически обновляются при изменении данных)

**Язык:** TypeScript

**Почему:** много виджетов, которые влияют друг на друга, и данные приходят из разных источников (WebSocket, REST и т.д.). Реактивный подход сам следит, что и когда обновить. TypeScript помогает не допускать ошибок и легче тестировать код.

---

## 4. Прошивка для датчика температуры

**Парадигма:** императивная (простой, прямой код без лишних абстракций)

**Язык:** C

**Почему:** очень мало памяти (256 KB и 32 KB) и нужен прямой доступ к железу. C лёгкий, быстрый и работает почти на любом чипе.
